• Drag a Shape : Hover Shapes in the bottom bar, then click a shape or drag it onto the canvas (or onto an arrow). Flow holds Start, End, Step and Decision; Classic the flowchart symbols: Subprocess (a process documented elsewhere), Data (input/output), Document, Database (stored data) and Delay (a wait)
  • Drop onto an Arrow : Inserts the step between the two steps it joins and tidies the layout (also works for a step with no arrows yet)
  • Click or Drag Port : Connect two steps with an arrow
  • Double-Click Arrow : Add or edit arrow label (or click + Add Label)
  • Delete : Delete the selected step, arrow or lane (or the bar's Delete button, shown while something is selected)
  • Click Lane Name : Select the lane (a reorder grip and a delete button appear under its name); Delete then asks to confirm and removes it with its steps and their arrows (undo brings them back; the last lane stays)
  • Drag Node : Drop a step into another lane (or onto an arrow). With Auto-Tidy on, the layout tidies itself after every step you add, move or delete (Ctrl+Z undoes both at once); with it off, steps stay where you drop them and snap to other steps' and lane centers
  • Reorder Steps : Rewire the arrows (drag an arrow's end to another step, or delete and redraw it). Arrow edits never re-arrange the diagram, so it holds still while you rewire; press Tidy (or edit a step) to lay out the new order
  • Auto-Tidy : Turn automatic layout on or off (remembered in this browser); Tidy lays the diagram out once, now
  • Note (under Shapes, Annotate) : Drag it onto a step to give that step a note, or click it to add one to the selected step (with nothing selected, click the step next; Esc cancels)
  • N : Add a note to the selected step (or click the + chip on the corner of a hovered or selected step); Enter starts a new line, Ctrl+Enter, Esc or a click elsewhere finishes, an empty note is removed
  • Link a Note : One note can explain several steps. Select the note, then drag its link handle (bottom-right corner) onto a step, or Shift+click the step; do the same on a linked step to unlink it
  • Note Badge : A step with a note shows a small badge: hover the badge (or the step) to peek at the note, click it to edit
  • Notes : Show or hide every note at once; they are fitted into the gaps between steps (saved with the file). Drag a note to place it yourself: it then follows its step. Double-click to edit, Delete removes the selected note
  • Vertical / Horizontal : Switch between a left-to-right and a top-to-bottom layout (lanes become columns); saved with the file
  • Show lanes : In a diagram drawn without swimlanes, the Lane button reads Show lanes and turns them back on (name the actor, then add more lanes)
  • Drag Lane Name : Drag a lane's name pill to reorder swimlanes (a blue line shows where it will land); double-click the name to rename
  • Double Click : Edit step text, lane names, or edge conditions
