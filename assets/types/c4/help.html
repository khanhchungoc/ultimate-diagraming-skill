• Levels : Level 1 (system context): every system is one box. Level 2 (containers): a system is opened to show its apps, services, databases and queues The model is one diagram; the level is which system groups are open
  • Chevron in a system's title : Collapse the group to one system box, or expand it to its containers. A collapsed system shows the lines that cross its border merged into one arrow per neighbour, with a count. The state is saved
  • Click : Select a person, system, container, group or arrow
  • Hover an element : its arrows in and out stay lit and the rest greys out
  • Arrows : each says what it does; the technology (REST, SQL, AMQP) is under the label; a dashed arrow is asynchronous
  • Colour : People and your own systems take a colour each (the legend says which); a third-party system is neutral and sits in its own boundary
  • Add (dock) : Click a tile (person, system, container, database, queue, external system or group) to add it; there is no dragging a tile onto the canvas. Added while a group is selected, it joins that group. The new item is selected and its name opens for editing
  • Select Several : Ctrl or Shift+click adds an element, group or arrow to the selection; hold Shift and drag on empty canvas to select the elements it covers (a plain drag pans the view; Ctrl+Shift toggles); Ctrl/Cmd+A selects all; Esc clears. The action bar of several shows how many are selected and offers Group (when elements are among them), Delete with the count and a colour row
  • Action bar of an element : Rename, Kind (person, system, container, database, queue, external), Icon (a picker with a search field and the icons in groups: People, Devices and apps, Infrastructure, Data, Messaging, Business, Security; the first entry restores the default of the kind; a logo: name whose pack is not installed is listed as missing), Colour (a swatch row; a colour not yet named in the colour key asks for its name), Group (no group, an existing group, or New group, which creates a group and moves the element into it), Centre, Side (auto, N, S, E, W), Details (technology and description), Connect and the bin
  • Action bar of a group : Rename, Kind (system or boundary), Colour, Collapse, Centre, Side, Ungroup (the members stay) and the bin (deletes the group and its members; with members it asks first). A group's colour tints its frame and is named in the colour key
  • Action bar of an arrow : edit its label, set its technology, toggle Async (dashed), Reverse and the bin. An arrow that merges several relations (it ends at a collapsed system) shows only their count and the bin; open the group to edit them
  • Double Click a name, or F2 or Enter : Rename the selection; Enter saves, Esc keeps the old name. An empty name is refused. Double-click a collapsed system tile to expand it; double-click its name to rename it. Space on a focused collapsed tile expands or collapses it
  • Colour key : Picking a colour that has no name yet opens its entry in the colour key; type what it means, or leave it empty. Double-click an entry to edit it later
  • Connect : Drag from a port (the dot on each side of an element, shown on hover and when selected) onto another element, or choose Connect in the action bar and click the target. The label box opens at once and a label is required; Esc there cancels the label and undoes the connection. An arrow to itself, is refused at once with a message. A second arrow between the same pair with the same label is refused after you type the label, and the new connection is dropped
  • Delete or Backspace : Remove the selection; an element's arrows go with it
  • Tab to an arrow label : Every label of a single arrow is reachable by keyboard. Enter or F2 edits it, Delete or Backspace removes the arrow. A label that merges several relations is not editable (open the group first)
  • Icon packs : An element can use a logo from a local pack, written logo:<pack>/<name> in the file. The logo keeps its own colours on a white disc. No pack is bundled; you build one from the vendor's download (see references/icon-packs.md). A missing pack shows the icon of the kind instead
  • Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z : Undo and redo every action. An add and its first rename, and a connection and its label, are one step each
  • Auto-Tidy : Always on. Every add, connect, delete, group change or collapse lays the diagram out again, so boxes are not moved by dragging
  • Centre and Side : Mark an element or group as a centre of the diagram (the rest rings round it), and ask for the side of the centre it sits on. A side is a hint, not an order. With no centre the layout flows down in layers
  • Present mode (?present) : Read only. The Level control, hover, selecting and collapse still work; the Find field is hidden
  • / or the Find field : Match names, technologies, groups and arrow labels; matches light up, Fit to matches zooms to them
  • Notes : Show every note on the canvas, or hide them
  • ↑ ↓ ← → : Move to the nearest element in that direction
  • Esc : Clear the selection
  • Save : Writes the diagram, including which systems are open, back to the page. Names you gave become the ids
