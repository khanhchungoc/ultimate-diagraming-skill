• Click : Select a participant, message, frame (its tag or border), branch divider or note
  • Drag from a lifeline's + to another lifeline : Draw a message at that row (onto the same lifeline: a self-message)
  • Drag a selected message's end handle : Move that end to another lifeline
  • + between two participant boxes : Insert a participant there
  • Drag Participant : Move sideways to reorder lifelines
  • Drag Message : Move up or down to change the order in time (dropped inside a frame, it joins it)
  • Shift + Click a second message, or Shift + drag on blank canvas : Select a range, then Frame wraps it
  • Drag a selected frame's top or bottom handle : Change the messages it covers
  • Action bar over the selection : message type, reverse, reply; participant kind; frame kind, colour, + branch
  • Double Click, Enter or F2 : Edit the text (Tab from a message label to its detail; Shift + Enter breaks a note's line)
  • ↑ ↓ / ← → : Walk the messages / the participants (Shift grows a range, Alt moves the message)
  • Chevron in a frame tag : Collapse the frame to one row, or expand it (also in ?present)
  • Numbers / Details : Show step numbers / show each message's detail under its arrow
  • Delete : Delete the selection (a participant with messages asks first; a frame keeps its messages)
  • Esc : Cancel the edit, then clear the selection
