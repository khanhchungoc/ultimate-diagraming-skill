• The four lines : Association: an actor takes part in a use case (an open arrow shows who starts it) «include»: from a use case to a part it always needs «extend»: from an optional addition to the use case it extends, only sometimes, with a condition Generalization: a specialised actor or use case points to the general one Always happens: include. Only sometimes: extend. Include points from the base to the part; extend points from the extension to the base
  • Click : Select an actor, use case, subject, line (or its label) or note
  • Click an Actor : Everything that actor can reach stays at full strength and the rest dims: its use cases and what they include or extend. Click it again or press Esc to clear. Click a Use Case lights its actors and its include, extend and generalization neighbours
  • / or the Find field : Match names and requirement ids (type FR-4 to find the use case that implements it); matches light up, Fit to matches zooms to them
  • Add (dock) : Click a tile to add it at the centre of the view, or drag it onto the canvas. A use case dropped inside a subject joins it. Its name opens for editing
  • Drag from an item's port (the dot on its edge) onto another item : an actor and a use case get an association, two use cases an include (switch it to extend in the line's action bar), two actors a generalization (the first becomes a kind of the second). Dropped on blank canvas inside a subject, it draws out a new use case already connected
  • Action bar of a line : Association / Include / Extend (choosing extend on an include reverses the line, because extend points to the base), Arrow on an association, then Reverse, the extend condition, Extension point (one of the base's points) and the bin
  • Double Click, Enter or F2 : Rename the selected item or subject; Enter commits, Esc keeps the old text
  • Select Several : Ctrl/Cmd+click adds an actor or use case or takes it out; Shift+drag on blank canvas draws a box (touching counts); Ctrl/Cmd+A selects all; Esc or a click on blank canvas clears. Drag one to move them all; dropped on another subject, the use cases move there. Delete removes them all (one Ctrl+Z brings them back)
  • Action bar of several : Colour recolours them all, Subject moves the use cases to another subject, Connect (one actor and N use cases selected) associates the actor with all of them, Delete N
  • Colour : Use cases take a colour per feature area (the legend says which); actors stay neutral unless you colour them. A use case's level is its size and outline (summary: large, bold; subfunction: small, dashed)
  • Chevron in a subject's title : Collapse the boundary to its name bar, or expand it (also in ?present)
  • Refs / Levels / Notes : Show requirement ids under each use case / show or hide the subfunction use cases / show every note on the canvas
  • Auto-Tidy : On: adding, deleting or connecting re-arranges the diagram. Off: things stay where you drop them (Tidy re-arranges once)
  • ↑ ↓ ← → : Move to the nearest actor or use case in that direction
  • Esc : Cancel what is under way, then clear the selection
