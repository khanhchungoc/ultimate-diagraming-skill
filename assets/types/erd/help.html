• Hover a Table : Light up the lines that enter it (amber: tables it is the parent of) and leave it (blue: tables it points to) and the joined column rows; everything else dims
  • Hover a Line : Light up the two columns it joins
  • Chevron in a table header : Collapse the table to its header, or expand it (also in ?present); the layout re-tidies
  • Columns : Cycle what every table shows: all columns, key columns only (with a "+ N more" row), or table names only; saved with the file
  • Types : Show or hide the column types
  • Notes : Show every note on the canvas at once, or hide them. A table with a note has a small badge: hover the badge (or the table) to peek at the note, click the badge to keep it open
  • Vertical / Horizontal : Switch between parents on the left and parents on top; saved with the file
  • Auto-Tidy : Turn automatic layout on or off (remembered in this browser); Tidy lays the whole diagram out once, now
  • Area name : Each subject area is a band with its name pill at the start; the pill stays at the visible edge when you pan past it
  • Reading a line : A crow's foot (three prongs) marks the "many" end, a bar "one", a circle "zero"; a solid line means the key is part of the child's primary key, a dashed one that it is not. Lines leave and enter at the column that holds the key
