• Ctrl + S : Save changes directly into HTML
  • Export (top right): download the whole diagram as an SVG or a 2x PNG, or copy it to the clipboard as a 2x PNG
  • Ctrl + Z / Ctrl + Y : Undo / redo the last edit (also Ctrl + Shift + Z)
  • ?present in the URL : Hide editing controls for a clean read-only view
  • Drag Canvas : Pan viewport
  • Scroll Wheel : Scroll the canvas up / down (Shift + wheel: left / right)
  • Ctrl + Scroll Wheel : Zoom in / out at the cursor
