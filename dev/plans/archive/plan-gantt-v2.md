# Plan: Gantt UX & Visual Polish v2 (Post-Testing Issues)

Root-cause analysis and phased implementation plan for the 16 issues found during interactive testing of `diagramType: "gantt"` on `stg` (`4fd43ca`).

---

## Root-cause analysis (all 16 issues)

| # | Issue | Root cause in current code | Target fix |
|---|---|---|---|
| 1 | **Cannot scroll into future / past timeline (fixed period)** | `engine.js` computes `_range` tightly from `min(items) - pad.before` to `max(items) + pad.after` (`GANTT_PAD_DAYS`: only 3–60 days). Users cannot scroll ahead to plan future quarters/years or drag a task beyond the fixed end. | Expand the virtual scrollable timeline range generously beyond item bounds (e.g., ±6 months in Day/Week, ±18 months in Month, ±3 years in Quarter/Year) AND auto-extend `_range` dynamically when the user scrolls near either edge or drags a bar near the edge, while keeping initial scroll anchored to the roadmap's start (or Today). |
| 2 | **Action bar doesn't follow shared component (`swatchPicker`, no Rename / Move Up-Down buttons)** | `gantt.js` builds a custom inline swatch row and extra `Rename`, `Move up`, `Move down` buttons instead of using `shell.js`'s shared `swatchPicker(current, setColor, { triggerClass: 'ab-btn', btnClass: 'ab-swatch', act: 'color' })` (which opens on hover, matching C4/Flowchart/ERD). Double-clicking a label already renames inline and row drag already reorders, so `Rename` and `Move up`/`Move down` clutter the bar. | Switch all Gantt action bars to `swatchPicker(...)` from `shell.js`; remove `Rename`, `Move up`, and `Move down` buttons (keep double-click / `F2` rename and keyboard `Alt+↑/↓` reorder for accessibility). |
| 3 | **No drag-and-drop from `+ Add` in toolbar onto the chart** | `#btn-add` popover tiles (`#btn-add-task`, `#btn-add-subtask`, `#btn-add-milestone`, `#btn-add-marker`, `#btn-add-note`) only have `click` handlers; there is no pointer-drag ghost drop onto a specific timeline row/date. | Add pointer-drag support on `+ Add` tiles (matching Flowchart/C4): dragging a Task/Milestone/Marker/Note tile shows a floating ghost, highlights the hovered date/row on `#gantt-body`, and drops the new item right at that exact date and row on release (clicking still adds immediately as before). |
| 4 | **Unnecessary Delete button on bottom toolbar** | `shell.html` / `shell.js` shows `#btn-delete-selection` when `plugin.hasSelection()` is true — `erd` and `usecase` (plus `e2e_erd.mjs` / `e2e_usecase.mjs`) still rely on it, so removing it from `shell.js` would break those types. `flowchart.css:622` and `sequence.css:252` hide it per-type instead. | Hide `#btn-delete-selection` in `gantt.css` (`#btn-delete-selection { display: none !important; }`), matching `flowchart` and `sequence`, while keeping `Delete` / `Backspace` shortcuts and the action bar's Delete button. |
| 5 | **Day view header (`23 Sa`) is ugly + Weekend toggle** | `gantt.js` `renderHeader()` writes `${day} ${WEEKDAY_SHORT.slice(0,2)}` on one cramped line (`23 Sa`, clipping `15 Mo`, `24 We` at 36px width!). Weekend shading is hard-tied to `GANTT_ZOOMS[zoom].showWeekends` with no user toggle. | In Day view, stack each day cell vertically as 2 clean centered rows: day number on top (`23`, semibold) and 3-letter weekday below (`Mon`, muted, small), widening `day` `pxPerDay` from `36` to `44px` so nothing clips. Add a `Weekends` toggle (in toolbar or Holidays/View menu, persisted as `showWeekends`, default `true` in Day/Week) to show/hide weekend shading. |
| 6 | **Cannot add holiday date ranges** | `#gantt-holidays-pop` in `chrome.html` only has a single `#gantt-hol-date` `<input type="date">`, even though the data model (`{ date, end, name }`), `mermaid.js`, and `engine.js` already support inclusive ranges! | Add an optional `#gantt-hol-end` ("End date, optional") input to `#gantt-holidays-pop` alongside `#gantt-hol-date` ("Start"), defaulting `end = start` when left blank, and validating `end >= start`. |
| 7 | **Header rows not frozen when task list is tall** | `#gantt-sidebar` and `#gantt-timeline` scroll separately; `.gantt-sidebar-head` is inside `#gantt-sidebar`, and `#gantt-tree` has `overflow-y: auto` vs `#gantt-timeline` scrolling both X and Y. When there are >18 rows, vertical scrolling can scroll `#gantt-header` or misalign vertical scroll between sidebar and timeline. | Make `.gantt-sidebar` a flex column where `.gantt-sidebar-head` is `flex: none` (always pinned at top) and `#gantt-tree` scrolls vertically in lockstep with `#gantt-body-scroll`, while `#gantt-header` stays pinned (`position: sticky; top: 0; z-index: 30;`) in `#gantt-timeline` with strict vertical scroll sync (`scrollTop` synced without jitter). Verify with a 30-row E2E test. |
| 8 | **No Collapse All / Expand All button** | `.gantt-sidebar-head` only has `TASKS` and `+`. Large roadmaps require clicking every phase chevron individually. | Add a compact Collapse All / Expand All icon button (`#btn-toggle-all`) in `.gantt-sidebar-head` next to `+` (toggles all parent items collapsed/expanded in one click, updating icon & tooltip). |
| 9 | **Font size accessibility & row height too tight** | `GANTT_METRICS.ROW_H` is `36px` (`BAR_H: 22px`), sidebar uses `var(--t-label-size)` (12–13px) and headers use `var(--t-overline-size)` (10–11px), which feels cramped on high-DPI screens. | Bump `ROW_H` from `36` → `44px` (`BAR_H: 26px`, `GROUP_BAR_H: 10px`, `HEADER_H: 58px`), and bump sidebar/header/milestone/tooltip font sizes up one token step (`13.5–14px` sidebar task names, `12px` header ticks, `12.5px` milestone labels). |
| 10 | **Timeline bars look transparent** | `.gantt-bar` uses `var(--sw-pill-bg)` (which is translucent/light) AND `[data-time-state="past"]` sets `opacity: 0.72`, allowing vertical gridlines and Today/holiday stripes to bleed visibly through the bar! | Give `.gantt-bar` an opaque solid light surface (`background: color-mix(in srgb, var(--sw-bg) 100%, var(--bg-panel))` or solid `--bg-panel` underlay) and replace `opacity: 0.72` on past bars with a solid muted color mix (never `opacity < 1` on the bar container), so gridlines never show through bars! |
| 11 | **Legend requires click instead of hover** | `#btn-legend` only toggles `#gantt-color-key` on `click`. | Open `#gantt-color-key` on hover (`mouseenter` on a wrapper containing `#btn-legend` + `#gantt-color-key`, closing smoothly on `mouseleave`), while keeping click/keyboard focus toggle working for touch and keyboard users. |
| 12 | **Collapsed chevron points left instead of right** | `assets/types/gantt/gantt.css:307` has `.gantt-chevron[aria-expanded="false"] svg { transform: rotate(-90deg); }` — rotating a downward chevron (`v`) by `-90deg` points it **left** (`<`) instead of **right** (`>`)! Wait: `chevron-down` rotated `-90deg` rotates counter-clockwise (pointing right in CSS if positive/negative: wait — in CSS `rotate(90deg)` is clockwise = left, `rotate(-90deg)` is counter-clockwise = right; let's verify in Chrome why it looked left — check the actual SVG path of `chevron-down` vs rotation!). | Fix the chevron rotation angle (`rotate(-90deg)` vs `rotate(90deg)` — verify visually in headless Chrome!) so expanded = `v` (down) and collapsed = `>` (right). |
| 13 | **Task name longer than sidebar column** | `.gantt-tree-label` uses `text-overflow: ellipsis` with no tooltip or easy way to read the full text without manually dragging the splitter. | Add full-text `title` / `data-tip` on `.gantt-tree-label` (automatically shown when truncated) AND allow double-clicking the `#gantt-splitter` handle to auto-fit the sidebar width to the longest visible task name! |
| 14 | **Don't show task name on timeline bar at all** | `gantt.js` still renders `.gantt-bar-label` inside wide bars (`Web application`, `Auth & SSO`, `Launch campaign`, `Docs & migration guide`), even though the left task column is frozen and always visible. | Remove `.gantt-bar-label` from task bars completely (never render task names on bars; hover tooltip shows just the date span like `Apr 1 – Apr 14 · 14d`). Keep row milestone labels next to diamonds only if desired, or keep bars completely clean. |
| 15 | **Dependency-adding UX is clumsy (tiny 10px ports copying flowchart)** | `.gantt-port-l` / `.gantt-port-r` are tiny `10×10px` circles offset `-12px` outside the bar — hard to hit, and you have to aim at another tiny port. | Redesign dependency linking for Gantt: (a) make connector handles larger, pill-shaped side grips (`18×18px` hit target with visible `10px` dot and clear `+` / arrow cursor) that appear smoothly right at the bar edges on hover; (b) allow dropping **anywhere** onto the target bar/milestone (not just a tiny port!) to create an FS link (or drag from left handle for SS), highlighting the entire target bar as a clear drop zone with a live preview curve and label (`After finish` / `Same start`)! |
| 16 | **Quick-add ghost bar when hovering empty timeline rows** | Currently, a newly added row with no dates (or a parent/placeholder row) shows nothing when you hover its empty timeline track. | Allow items without `start`/`end` (unscheduled tasks) AND when hovering an empty row's timeline track, show a translucent dashed ghost bar snapped to the hovered date (`+ Click or drag to schedule · May 20`); clicking creates a default 7-day bar at that date, or dragging paints the exact start→end span immediately! |

## Phased implementation plan

### Phase 1: Engine & Layout Foundation (`engine.js`, `disk_format.py`, `mermaid.js`)
- **Expanded & dynamic timeline range (`#1`):** Increase `GANTT_PAD_DAYS` generously per zoom level (e.g., Day: ±90d, Week: ±180d, Month: ±365d, Quarter: ±730d, Year: ±1095d) and support optional runtime range expansion (`_extraStart` / `_extraEnd`) when scrolling/dragging near timeline edges while keeping disk format and deterministic default layout intact.
- **Bigger row & bar metrics (`#9`):** Update `GANTT_METRICS` (`ROW_H: 44`, `BAR_H: 26`, `GROUP_BAR_H: 10`, `HEADER_H: 58`) and `GANTT_ZOOMS.day.pxPerDay: 44` (for crisp 2-line Day headers).
- **Optional unscheduled tasks (`#16`) & `showWeekends` (`#5`):** Allow leaf tasks with omitted `start`/`end` in `engine.js` (`_bar: null`, row still rendered cleanly) and add optional `showWeekends` boolean to `GANTT_KEYS` in `disk_format.py` + `gantt.js` `toDisk`.
- **Tests:** Update `test_gantt_engine.mjs` for new metrics, expanded range, and unscheduled task rows.

### Phase 2: Visual & Accessibility Overhaul (`gantt.css`, `stage.html`, `chrome.html`, `toolbar.html`)
- **Day view 2-row header (`#5`):** Render Day ticks with `<span class="gantt-day-num">23</span><span class="gantt-day-dow">Mon</span>` stacked vertically. Add `Weekends` toggle button in dock/menu.
- **Frozen headers on tall lists (`#7`):** Lock `.gantt-sidebar-head` and `#gantt-header` cleanly while `#gantt-tree` and `#gantt-body` scroll vertically in lockstep.
- **Opaque bars (`#10`) & no bar text (`#14`):** Solid non-transparent bar fills (opaque base + solid muted past tint, never `opacity < 1` on `.gantt-bar`), and remove `.gantt-bar-label` inside bars (hover tooltip shows full name + dates).
- **Typography & row height (`#9`):** Bump sidebar, header, and milestone font sizes up one token tier; align CSS `--gantt-row-h: 44px`, `--gantt-bar-h: 26px`, `--gantt-header-h: 58px`.
- **Chevron direction (`#12`), Collapse/Expand All (`#8`), Splitter auto-fit (`#13`), Hide `#btn-delete-selection` (`#4`), Hover Legend (`#11`):** Fix collapsed chevron rotation to point right (`>`), add `#btn-toggle-all` in `.gantt-sidebar-head`, double-click splitter to auto-fit longest task name + tooltips on truncated labels, hide `#btn-delete-selection`, and open `#gantt-color-key` on hover (with click/keyboard fallback).
- **Holiday date ranges (`#6`):** Add `#gantt-hol-end` input to `#gantt-holidays-pop` so users can add single-day or multi-day holiday ranges.

### Phase 3: Interaction Upgrades (`gantt.js`)
- **Shared Action Bar (`#2`):** Replace custom color swatches with `shell.js`'s `swatchPicker(...)` (hover-open, matching C4/Flowchart/ERD); remove `Rename`, `Move up`, and `Move down` buttons (keep double-click / `F2` rename and `Alt+↑/↓` keyboard reorder).
- **Drag-and-drop from `+ Add` (`#3`):** Support dragging Task, Subtask, Row Milestone, Date Line, and Note tiles from `#gantt-add-pop` directly onto any timeline date/row with a live ghost preview.
- **Better dependency-linking UX (`#15`):** Larger hit-target side connector grips (`18×18px`) + whole-bar drop zones + live curve preview with `After finish` / `Same start` badge.
- **Hover ghost bar on empty rows (`#16`):** Hovering an unscheduled row's timeline track displays a subtle dashed ghost bar snapped to the cursor date; click to place a 7-day bar or drag to paint start→end dates directly.

### Phase 4: Verification & Screenshots
