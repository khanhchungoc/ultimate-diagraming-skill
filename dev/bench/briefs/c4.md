# Brief: Online shop landscape (C4 diagram, Level 1 and Level 2)

Scope: the ShopCo system landscape, opening with the Order Platform expanded.

People: Customers buy products online through the web shop. Support agents answer order questions and look customers up in the CRM. Warehouse staff pack and ship orders and manage shipments in the same web shop.

ShopCo systems: the CRM holds customer records. The Order Platform is made of a Web App (React), an API Gateway (Node.js, REST), an Order Service (Java, Spring), an Order DB (PostgreSQL), an Event Bus (RabbitMQ) and a Fulfilment Worker (Python).

Flows: the Web App calls the API Gateway over JSON/HTTPS; the gateway routes requests to the Order Service over gRPC; the Order Service reads and writes orders in the Order DB over SQL, publishes order events to the Event Bus over AMQP, and the Fulfilment Worker consumes them over AMQP. The Order Service charges cards through the Payment Provider (REST), gets tax rates from the Tax Service (REST) and syncs customers with the CRM (REST). The Fulfilment Worker books carriers through the Carrier API (REST), sends receipts through the Email Service (SMTP) and delivery alerts through the SMS Gateway (REST); those three are fire-and-forget.

Third parties: Payment Provider, Email Service, Carrier API, Tax Service and SMS Gateway are not owned by ShopCo.
