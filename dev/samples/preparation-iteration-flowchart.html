Shortcuts & Interaction
  • Drag a Shape : Hover Shapes in the bottom bar, then click a shape or drag it onto the canvas (or onto an arrow)
  • Drop onto an Arrow : Inserts the step between the two steps it joins and tidies the layout (also works for a step with no arrows yet)
  • Click or Drag Port : Connect two steps with an arrow
  • Double-Click Arrow : Add or edit arrow label (or click + Add Label)
  • Delete : Delete the selected step, arrow or lane (or the bar's Delete button, shown while something is selected)
  • Hover a Lane : Shows a reorder grip (drag it) and a delete button (asks to confirm) under the lane name
  • Click Lane Name : Select the lane; Delete then asks to confirm and removes it with its steps and their arrows (undo brings them back; the last lane stays)
  • Drag Node : Move inside lane or drop into another lane; snaps to other steps' centers and lane centers (dashed guide)
  • Vertical / Horizontal : Switch between a left-to-right and a top-to-bottom layout (lanes become columns); saved with the file
  • Drag Lane Name : Drag a lane's name pill to reorder swimlanes (a blue line shows where it will land); double-click the name to rename
  • Double Click : Edit step text, lane names, or edge conditions
  • Ctrl + S : Save changes directly into HTML
  • Export (top right): download the whole diagram as an SVG or a 2x PNG
  • Ctrl + Z / Ctrl + Y : Undo / redo the last edit (also Ctrl + Shift + Z)
  • ?present in the URL : Hide editing controls for a clean read-only view
  • Drag Canvas : Pan viewport
  • Scroll Wheel : Scroll the canvas up / down (Shift + wheel: left / right)
  • Ctrl + Scroll Wheel : Zoom in / out at the cursor
