Shortcuts & Interaction
  • Click : Select a table (its header), a column (its row), a line (or its label) or a note
  • Hover a Table (or select one) : Show its neighbourhood. The tables that point at it (children, amber) and the tables it points to (parents, blue) get a coloured ring, the lines between them light up, and the joining columns are tinted and bold with a chip: → customer.id on a child's key, ← order.customer_id (or ← 3 columns) on a parent's. When a related table does not show those rows (Columns set to keys or names, or collapsed) a small card under its header lists them. Everything else dims
  • Hover a Line : Light up the two columns it joins
  • Table (dock) : Add a table after the selected one, with an id primary key (uuid); its name opens for editing. Or drag the button onto the canvas to drop it where you want it
  • Double Click, Enter or F2 : Rename the selected table or column, edit a line's label. In a column, Tab goes name, then type, then the next row; Enter on the last row adds a column; an empty name and Enter removes it; Esc keeps the old text. Renaming a column renames it in every relationship
  • + Column in a table's action bar : Add a column at the end
  • PK / FK / U / ? in a column's action bar, or P F U ? on a selected row : Toggle primary key, foreign key, unique, nullable
  • Drag a row, or Alt + ↑ / ↓ : Move the column up or down in its table. Deleting a column removes it from the relationships that name it
  • Drag from a column's port (the dot at the right edge of a hovered row, or of the header) onto another table or column : Draw a relationship from the table that holds the key (the child) to the table it points to (the parent). From a column onto a column, the start column becomes a foreign key, the line is dashed (solid when that column is part of the primary key) and the ends are zero-or-many to one (zero-or-one for a nullable column). Onto a table header, no column is named. Onto the same table's key: a self-reference
  • Relationship (dock) : Arm the tool, then drag from any column to another table; Esc cancels
  • Drag a selected line's end handle : Move that end to another table or column
  • Action bar of a line : two rows of crow's-foot buttons (Child end, Parent end: exactly one, zero or one, one or many, zero or many), Identifying (solid or dashed), reverse (swap child and parent) and label
  • Colour swatches in a table's action bar : Tint the table (all selected tables at once) with one of the eight colours; none clears it. Give each domain (billing, accounts...) its own colour: related tables then read as a group without a box around them. Naming a colour is optional: a tinted table's bar has Name colour, which adds that colour to a legend above the tables (double-click an entry, or select it and press Enter, to rename it; clear the text to remove it). Without names there is no legend
  • Drag a table : Move it anywhere (dashed guides snap it to another table's centre); only its lines re-route, nothing else moves. Tables it would overlap are pushed aside
  • Zoomed out : Below 50% zoom the diagram becomes an overview: tables show only their names, lines keep a fixed thickness, labels keep a readable size (hover a table to see its related tables' joining columns). Zoom in past 60% for the full tables; double-click a table in the overview to zoom to it
  • Note (dock), N or the + chip on a hovered table : Add a callout note to a table (or click/drag Note onto a table header). With nothing selected, N or a click on Note adds a free note at the centre of the view, and dropping Note on empty canvas makes one there. Enter breaks a line; Ctrl + Enter, Esc or a click away finishes; an empty note is dropped. A table with a note has a badge: hover it to peek, click it to edit. On a column, N, its action bar's note button or clicking/dragging Note onto a row adds an inline note directly next to the column name (double-click to edit, clear it to remove)
  • Drag a note's card : Pin it where you drop it. Drag its link handle onto another table (or Shift + Click a table while the note is selected) to link it, and onto a linked table to unlink it. A free note (linked to no table) stays where it is, always on show, with no leader or badge, and Tidy never moves it; dragging its link handle onto a table links it. Unlinking never makes a note free
  • Select Several Tables : Ctrl/Cmd+click adds a table to the selection or takes it out; Shift+drag on blank canvas draws a box (with Ctrl/Cmd too, each table it touches is added or taken out); Ctrl/Cmd+A selects every table; Esc or a click on blank canvas clears it. Drag any of them to move them all; Delete removes them all with their relationships (one Ctrl+Z brings them back)
  • ↑ ↓ / ← → : Walk the columns of a table / the tables
  • Delete : Delete the selection: a table (it asks first when it has relationships, and removes them), a column, a line or a note
  • Esc : Cancel what is under way (a drawing, a drag, an armed tool), then clear the selection
  • Chevron in a table header : Collapse the table to its header, or expand it (also in ?present)
  • Columns : Cycle what every table shows: all columns, key columns only (with a "+ N more" row), or table names only; saved with the file
  • Types : Show or hide the column types
  • Notes : Show every note on the canvas at once, or hide them
  • Tidy : Re-arrange the whole diagram afresh, once, now. Edits never move the tables: a new table goes beside its neighbours, and lines re-route
  • Reading a line : A crow's foot (three prongs) marks the "many" end, a bar "one", a circle "zero"; a solid line means the key is part of the child's primary key, a dashed one that it is not. Lines leave and enter at the side of a table that faces the other one; hover a table to see which columns they join
  • Touch : drag with one finger to pan, pinch with two to zoom. Tap a table to select it: its column dots then show, and a drag from one draws a relationship; a drag on the selected table moves it. Tap a line to select it, then drag its end handles
  • Ctrl + S : Save changes directly into HTML
  • Ctrl + F or / : Search the diagram's text. Enter / Shift + Enter (or the arrow buttons) go to the next / previous match, Esc closes the search
  • Export (top right): download the whole diagram as an SVG or a 1.5x PNG, or copy it to the clipboard as a 1.5x PNG
  • Ctrl + Z / Ctrl + Y : Undo / redo the last edit (also Ctrl + Shift + Z), or the buttons at the bottom left
  • More (⋯, top right) : Paste Mermaid (replace the diagram from Mermaid text; Ctrl + V on the canvas does the same), Dark mode, and this list of shortcuts (?)
  • Present (top right) or ?present in the URL : a read-only view with only the zoom controls. Pan, zoom, hover and click still work; Esc or the Present button exits
  • Drag Canvas : Pan viewport
  • Scroll Wheel : Scroll the canvas up / down (Shift + wheel: left / right)
  • Ctrl + Scroll Wheel : Zoom in / out at the cursor
  • Touch : drag with one finger to pan, pinch with two to zoom. A drag that starts on an item pans unless the item is already selected; tap an item to select it, then drag it
