Shortcuts & Interaction
  • Click : Select a participant, message, frame (its tag or border), branch divider or note
  • Drag from any lifeline or activation bar (or its +) to another lifeline : Draw a message at that row. Drawn back to a caller still waiting on its call, it is that call's reply; otherwise a call. Out to the side and back onto the same lifeline: a self-message. On touch, tap the lifeline first
  • Drag a selected message's end handle : Move that end to another lifeline
  • + between two participant boxes : Insert a participant there
  • Drag the handle at the bottom of an activation bar (hover it, or select the call that opens it) to a later message : Keep that participant busy until that message. Reset bar in the action bar undoes it
  • Drag Participant : Move sideways to reorder lifelines
  • Drag Frame or Note from the dock onto the diagram : an outline shows the frame around the arrow under the pointer, and dropping wraps that arrow (drag its edges to cover more); a note sits over the lifeline it is dropped near, or where it is dropped
  • Drag Message : Move up or down to change the order in time (dropped inside a frame, it joins it)
  • Shift + Click a second message, or Shift + drag on blank canvas : Select a range, then Frame wraps it
  • Drag a selected frame's top or bottom handle : Change the messages it covers
  • Action bar over the selection : No reply expected (async), reverse, reply, Note, Frame; participant kind, Note; frame kind, colour, + branch
  • Double Click, Enter or F2 : Edit the text (Tab from a message label to its detail; Shift + Enter breaks a note's line)
  • ↑ ↓ / ← → : Walk the messages / the participants (Shift grows a range, Alt moves the message)
  • Chevron in a frame tag : Collapse the frame to one row, or expand it (also in ?present)
  • Focus in a frame tag : Collapse every other phase and expand this one; the participants the others leave become thin rails (click a rail to select it, Show opens the frames hiding it). Press it again, or Show all in the dock, to expand everything (also in ?present)
  • Trim lifelines : Draw each lifeline only from its participant's first message to its last. A box then sits at the start of its lifeline, and the pinned row names only the lifelines alive under it
  • Drag a participant's box onto another lifeline (with Trim lifelines on) : They share one column, if they are never active together (otherwise it says when they are). Own column in the action bar undoes it. The handles on a selected participant's start box and cap make its lifeline begin earlier or end later
  • Colour swatches in a selected participant's action bar : Colour a participant by who owns it (its box, lifeline, bars and rail). The key above the diagram says what each colour means: double-click an entry to name it
  • Numbers / Details : Show step numbers / show each message's detail under its arrow
  • Delete, or the bin in the action bar : Delete the selection (a participant with messages asks first). A frame's bin asks whether to delete the frame only (its messages stay) or the frame with its messages; the Delete key removes the frame only
  • Esc : Cancel the edit, then clear the selection
  • Ctrl + S : Save changes directly into HTML
  • Ctrl + F or / : Search the diagram's text. Enter / Shift + Enter (or the arrow buttons) go to the next / previous match, Esc closes the search
  • Export (top right): download the whole diagram as an SVG or a 1.5x PNG, or copy it to the clipboard as a 1.5x PNG
  • Ctrl + Z / Ctrl + Y : Undo / redo the last edit (also Ctrl + Shift + Z), or the buttons at the bottom left
  • More (⋯, top right) : Paste Mermaid (replace the diagram from Mermaid text; Ctrl + V on the canvas does the same), Dark mode, and this list of shortcuts (?)
  • Present (top right) or ?present in the URL : a read-only view with only the zoom controls. Pan, zoom, hover and click still work; Esc or the Present button exits
  • Drag Canvas : Pan viewport
  • Scroll Wheel : Scroll the canvas up / down (Shift + wheel: left / right)
  • Ctrl + Scroll Wheel : Zoom in / out at the cursor
  • Touch : drag with one finger to pan, pinch with two to zoom. A drag that starts on an item pans unless the item is already selected; tap an item to select it, then drag it
