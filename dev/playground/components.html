Leaf row (spacer)

Connection port (ui.port)

Hover a box to show its ports; the first box shows them always (.is-shown). Ports are hidden while dragging (.is-dragging above them), several selected (.is-multi), editing, exporting, presenting.

Shown
.port.is-shown
Hover me
rest: hidden; hover: shown
Dragging
.is-dragging: no ports
Several selected
.is-multi: no ports
.port-end: a line's end handle
Touch size
.is-touch ancestor: --port-size-touch

One line that ends in an ellipsis when too long
.edge-label--single
